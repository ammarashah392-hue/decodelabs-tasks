# Interior Design Projects:

Welcome to my Interior Design Projects repository. This project showcases technical drawings and schematics completed during my internship at Decodelabs. It demonstrates my skills in computer-aided design (CAD), engineering visualization, and technical documentation.

### Repository Contents

#### Project 1: Process Flow Schematic / Piping and Instrumentation Diagram (P&ID)
* File: project-1.jpg
* Description: A clean instrumentation schematic detailing fluid or process flows through mechanical equipment.
* Key Deliverables:
    * Mapped equipment layouts using standard process symbols.
    * Identified and labeled core components including Storage/Tank (T-101), Valve (V-101), Pump (P-101), Pressure Indicator (PI-101), and Check Valve (CV-101).

#### Project 2: Orthographic and Isometric Mechanical Drawing
* File: project-2.pdf
* Description: A complete 2D and 3D engineering technical drawing of a mechanical component. 
* Key Deliverables:
    * Created an accurate Isometric View for 3D visualization.
    * Detailed full Orthographic Projections including Top View, Front View, and Right Side View.
    * Applied industry-standard dimensioning techniques for radii, diameters, and linear lengths.
